¿Cómo funciona?

Regla de 3 directa

Se usa cuando si una cantidad aumenta, la otra tambien aumenta (o ambas bajan). Ejemplo: mas kilos, mas precio.

Regla de 3 indirecta

Se usa cuando una sube y la otra baja. Ejemplo: mas velocidad, menos tiempo para llegar.

Ver ejemplo rapido para ninos

Directa: 2 caramelos cuestan 4. ¿Cuanto cuestan 5 caramelos? Cuantos mas caramelos, mas cuesta.

Indirecta: 2 personas pintan una pared en 6 horas. ¿Cuanto tardan 4 personas? Si hay mas personas, tarda menos.
